# Melhorias pós-MVP

Ideias para evoluir o **EsilvaSoft.KapibaraStudio — Studio — MongoDB Database Management & Development Tool**. Este catálogo registra possibilidades, não compromissos de entrega. O produto continua sendo uma aplicação desktop para gestão cotidiana de bancos MongoDB e desenvolvimento.

## Como ler

Cada conceito separa o benefício, o que já existe, a extensão possível e suas dependências ou limites. “Já existe” descreve o recorte documentado, não homologação completa em todos os sistemas, servidores ou ambientes. Nenhum item presume fase, versão ou data.

A prioridade atual de IA local, incluindo o caminho CPU e a infraestrutura de avaliação KapiLab necessária para desenvolvê-la com evidência, permanece no MVP/trabalho vigente. Aceleração por GPU/NPU é opcional e condicionada a hardware e validação próprios. KapiLab é ferramenta interna de desenvolvimento, não funcionalidade exigida de quem usa o Studio.
