## Saída e evidências

Concluir somente quando cada critério obrigatório aplicável da [fase oficial](../../docs/MVP/fases/fase-06-v0.15.0.md) tiver evidência proporcional. Falha, ignorado ou ambiente ausente mantém o critério aberto. Reutilizar evidências históricas apenas no seu alcance; registrar nova execução com snapshot e ambiente próprios.

Seguir as [regras comuns](../README.md#regras-comuns-de-validação) e o [procedimento oficial](../../docs/MVP/06-validacao-e-evidencias.md). Atualizar entregas da fase a partir das evidências das tarefas; não manter cópia do estado dos requisitos neste índice.
